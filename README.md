# AWS Cloud Engineering Lab

Hands-on cloud engineering project demonstrating AWS infrastructure design, Infrastructure as Code (IaC), automation, networking, security, and CI/CD.

## Project Overview

This project builds and manages AWS infrastructure using Terraform. The goal is to demonstrate practical cloud engineering skills through a production-style AWS environment.

## Current Architecture

- AWS Region: us-east-2 (Ohio)
- VPC: 10.0.0.0/16
- Public Subnet 1: 10.0.1.0/24 - us-east-2a
- Public Subnet 2: 10.0.2.0/24 - us-east-2b
- Internet Gateway
- Public Route Table
- Multi-Availability Zone network design
